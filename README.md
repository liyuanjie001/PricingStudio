# Pricing Studio

先定价格，再算积分。根据每份套餐的价格、优惠和毛利率，计算成本预算与建议积分；可以手动调整发放积分，核对实际成本和利润。

## 启动

使用 Node.js 22.12+ 或 Node.js 24 LTS，安装依赖并运行：

```sh
npm install
npm run dev
```

访问 **http://localhost:5174/**，无需访问密码。默认端口为 5174；端口被占用时会明确报错，不自动切换到其他项目。

```sh
npm test          # 计算、状态、输入、迁移、界面流程和 Excel 回读测试
npm run build    # TypeScript 检查及生产构建
npm run preview  # 预览生产构建
```

## 使用方法

1. 选择或新增个人版、团队版套餐，设置价格、账号数量和购买周期。
2. “毛利率”显示当前实际结果，也可以直接修改。输入新毛利率后，根据折后实收与账号成本重新计算积分。
3. 修改折扣保持已配置积分和成本不变，毛利率、利润及视频单价实时变化。
4. 个人版也可直接修改发放积分；再次修改毛利率会按输入值重新配置积分，替代此前的手动积分。

界面仅保留一个可编辑的“毛利率”，不再分开显示目标值与实际值，也不显示“保持 · 重新计算”、积分模式和恢复自动按钮。金额仍以完整套餐周期为单位；年付与季付分别保存。

例如：原价 ¥500、2 个季度账号、按 62% 配置得到 690 积分、成本 ¥190。优惠改成 5% 后实收 ¥475，积分不变，毛利率显示 60%。把毛利率改为 62% 后，积分重算为 642，总成本 ¥180.40，最终毛利率为 62.02%。

桌面端左侧设置套餐、右侧对比全部个人版与团队版套餐。点击表格行切换左侧套餐，数字可直接在表内修改。套餐对比保留 15 列，其中仅一列为“毛利率”，支持按该列排序。较窄屏幕展示含全部字段的卡片，不需要横向滚动。

## 计算规则

- 实收金额 = 原价 × (1 − 优惠百分比 / 100)。
- 修改毛利率时的成本预算 = 实收金额 × (1 − 输入毛利率 / 100)。
- 账号成本 = 账号数量 × 周期账号单价（季付 ¥26，年付 ¥104）。
- 积分预算 = max(0, 成本预算 − 账号成本)。
- 个人版发放积分 = floor(积分预算 / 每积分成本)。
- 团队版每席积分 = floor(积分预算 / 席位数 / 每积分成本)，总积分 = 每席积分 × 席位数。
- 总成本 = 账号成本 + 总积分 × 每积分成本。
- 总利润 = 实收金额 − 总成本。
- 毛利率 = 总利润 / 实收金额 × 100%。
- 个人视频数 = floor(发放积分 / 11)；团队视频数 = floor(每席积分 / 11) × 席位数。
- 视频单价 = 实收金额 / 视频数；无视频时显示“—”。

积分向下取整，显示的毛利率以最终成本计算，可能略高于输入值；不会为了强行匹配输入而隐藏取整结果。仅格式化显示，不按界面舍入值反复更新底层配置。账号成本超过预算时积分为 0，仍计入全部账号费用并显示能实现的毛利率。

毛利率允许显示和设置负值。可设置值必须小于 100%；零成本产生的实际 100% 可正常显示。零收入时显示“—”，需要先设置售价才能编辑毛利率。无效输入保留草稿和最后有效计算结果，修正前不能导出或命名保存。

团队最低 2 席，所有席位共用价格与每席积分。增减席位只改变总量与毛利率，不改变每席积分；修改毛利率、价格或账号数会重新配置每席积分。修改折扣不重算任何版本的积分。

“方案设置”中的积分成本应用于当前方案。个人版手动配置的积分不随单价变化；通过毛利率自动配置的积分及团队积分会重算。数据计算使用 Decimal.js，内部精度为 32 位，界面毛利率保留最多两位小数。

## 方案与导出

方案保存于当前浏览器 LocalStorage。有效修改在 350ms 后自动保存，刷新或关闭页面前补存最后有效状态。支持另存、切换、重命名和删除方案。

无效数字保留编辑草稿和最后有效计算结果，阻止命名保存及导出。切换编辑套餐或方案会丢弃该视图未生效的无效草稿。

Excel 导出包含“方案设置”“套餐对比”“团队席位”“团队汇总”“全部套餐对比”五个工作表。所有表按每个套餐自己的周期导出完整金额与积分，并保留周期标识。年付和季付可以同时出现在同一个工作簿中。金额、百分比、数量分别以适当数值格式导出；不支持导入。

### 统一套餐表与年付

- 底部“全部套餐对比”始终展示个人版和团队版所有套餐，切换版本只改变上方计算器。点击表中的套餐名称，可打开对应版本和套餐。
- 购买周期保存在每个套餐里，不再是方案级开关。默认季付，勾选“按年购买”只转换当前套餐，首次转换以原价 ×4 初始化；之后直接编辑全年价格、折扣、毛利率和账号数。
- “另建年付套餐”保留当前季付套餐并创建独立年付套餐。年付和季付拥有各自配置，可分别命名、编辑、复制、删除和保存，互不影响。
- 所有输入和结果均为该套餐的完整周期。账号单价季付 ¥26、年付 ¥104；席位数、账号数不乘四。年付积分按全年预算计算；完整视频数 = floor(本周期积分 / 11)，团队按每席取整后乘席位数。
- 个人套餐表的年付、季付原价和积分均可直接编辑，表格不再切换全局周期。
- 团队套餐表也可直接修改席位数、每席原价、优惠、毛利率和账号数，与左侧计算器双向同步。增减席位及修改折扣均保持每席积分不变；价格、目标或账号变更后重新计算积分。团队原价输入为每席价格，下方显示套餐合计。
- “视频个数”后展示“视频单价” = 折后实收总额 ÷ 实际视频个数，个人版和团队版口径相同；没有视频时显示“—”。团队视频数按每席向下取整后汇总，年付按全年视频数计算。Excel 的个人、团队及全部套餐对比中同步导出视频单价数值。
- 原方案级季付迁移为各套餐季付；原方案级年付将季度金额转为年金额，保留套餐数量及原始积分配置备份。迁移只执行一次，刷新不再乘四。缺失周期默认季付，重置恢复季付示例。

新版存储键为 `pricing-studio:v2`。首次发现 `pricing-studio:v1` 时会迁移套餐名称、原价、优惠、合法毛利率和备注，重新计算建议积分；旧销量和成本不视为积分。原始 v1 数据保留，另存一份 `pricing-studio:v1:backup`，不会覆盖已有备份。不适用的旧毛利率改为 35% 并提示检查。

未包含账号字段的已有 v2 方案会补充账号数量 0，不改变已有价格、积分或利润。重置只影响当前方案，将恢复四个示例套餐、账号数量 0 及 ¥0.2／积分。删除和重置均需确认。清除浏览器数据会删除本地方案，可提前另存方案和导出 Excel。

## 开发结构

- `src/domain.ts`：纯计算函数、校验、套餐与方案类型、reducer、旧版迁移。
- `src/storage.ts`：本地读取、版本迁移、备份与异常恢复。
- `src/App.tsx`：简化两栏界面、套餐对比和方案管理。
- `src/NumberField.tsx`：支持删除、小数草稿和光标保持的数字输入。
- `src/export.ts`：按需加载 ExcelJS，生成并下载 XLSX。

无后端、无遥测、无需密码；字体随应用打包，运行时不请求外部字体或 CDN。桌面端两栏，手机端上下排列。套餐对比在宽屏完整展示所有列，较窄屏幕转为含全部字段的套餐卡片，无需横向滚动，仍可编辑和排序。

左右面板与计算卡片间距为 16px，桌面页面两侧留白为 20px。表格正文为 13px、表头 12px、辅助说明 11px；对比区不足 1200px 时显示完整字段卡片。输入框宽度由所在栏位决定，清空数字仍保留输入草稿及最后有效结果；错误提示和保存状态预留空间，避免正常校验挤动布局。
